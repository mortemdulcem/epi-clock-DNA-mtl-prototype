2. Teknik Entegrasyon: Repo + UNODC UI Nasıl Konuşur?
Epi-clock projesi için en pratik akış şu olur:

Backend katmanı: Projendeki model kodunun üzerine küçük bir Flask veya FastAPI katmanı koyuyorsun.
Frontend: Şu an birlikte yazdığımız HTML + Tailwind sayfaları, bu API’ye fetch() ile istekte bulunuyor.

Ve sayfa sonunda:

Kopyala
<script>
  const runBtn = document.getElementById("run-epiclock-btn");
  const resultArea = document.getElementById("epiclock-result");

  runBtn.addEventListener("click", async () => {
    // Bu ID’yi sayfanın gerçek verisinden alabilirsin
    const sampleId = "SAMPLE-001";

    try {
      const res = await fetch("/api/epiclock/predict", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          sample_id: sampleId,
          // features: ...  (gerçek sistemine göre doldur)
        })
      });

      const data = await res.json();

      resultArea.innerHTML = `
        <div class="space-y-1">
          <p><span class="font-semibold">Örnek ID:</span> ${data.sample_id}</p>
          <p><span class="font-semibold">Kronolojik yaş:</span> ${data.chronological_age}</p>
          <p><span class="font-semibold">Epigenetik yaş (tahmin):</span> ${data.predicted_epigenetic_age.toFixed(1)}</p>
          <p><span class="font-semibold">Yaş ivmesi (age acceleration):</span> ${data.age_acceleration.toFixed(1)}</p>
          <p><span class="font-semibold">MAE:</span> ${data.mae.toFixed(2)} · <span class="font-semibold">RMSE:</span> ${data.rmse.toFixed(2)}</p>
        </div>
      `;
    } catch (err) {
      console.error(err);
      resultArea.innerHTML = `
        <p class="text-red-600 text-xs">Analiz çalıştırılırken bir hata oluştu.</p>
      `;
    }
  });
</script>
Bu şekilde:

Projendeki ML modeli değişmeden çalışır,
Sadece bir API sarmalayıcı koymuş olursun,
UNODC tarzı HTML/Tailwind arayüz, bunu front-end’ten kullanır.
